# UART 异步串行通信原理详解

## 引言

UART（Universal Asynchronous Receiver/Transmitter，通用异步收发传输器）是嵌入式系统中最基础、应用最广泛的串行通信接口，协议实现简单、硬件成本低，广泛用于芯片间调试、外设控制、固件下载等场景。

## 一、UART 核心定义与基本特征

UART是一种**点对点异步串行通信协议**，实现两设备间全双工数据传输，核心特征如下：

1. **异步机制**：无共用时钟线，收发双方通过约定波特率实现位同步，依靠起始位下降沿完成帧边界识别。
2. **串行传输**：数据按位在单根线上逐位传输，字节内遵循低位优先（LSB First）的传输顺序。
3. **全双工通信**：发送线（TX）与接收线（RX）相互独立，双向数据传输可同时进行。
4. **点对点拓扑**：仅支持两设备直连，无总线寻址能力，无法实现多设备组网。

## 二、UART 帧格式与关键参数

UART以 **“帧”** 为传输单位，单帧承载1字节有效数据，辅以同步、校验与结束标识。

### 2.1 标准帧结构

按传输顺序，单帧数据由四部分组成：

- **起始位（1位）**：总线空闲时为高电平，发送端拉低1个比特周期作为帧同步信号；接收端检测到**下降沿**即判定一帧开始。
- **数据位（5~8位）**：有效载荷，工业标准配置为8位，对应1字节数据。
- **校验位（0~1位，可选）**：用于检错，分为奇校验、偶校验两种模式；无校验时该位省略。
- **停止位（1~2位）**：数据线恢复高电平，标识单帧结束并提供帧间隔，标准配置为1位。

总线空闲状态下，数据线持续保持高电平。

### 2.2 核心参数定义

- **波特率**：单位时间传输的码元数，单位bps。UART为二进制调制，波特率与比特率数值相等。常用值：9600、115200、921600。
- **数据位宽度**：单帧有效数据位数，标准配置为8位。
- **校验方式**：分为无校验、奇校验、偶校验；无校验传输效率最高，为工业通用配置。
- **停止位长度**：1位、1.5位、2位；停止位越长容错性越强，传输效率越低。

通用标准配置记为 **8N1**：8位数据位、无校验、1位停止位。

### 2.3 有效传输速率计算

以115200波特率、8N1配置为例：

```
单帧总位数 = 1起始位 + 8数据位 + 1停止位 = 10位
有效数据速率 = 115200 × (8/10) = 11520 B/s
```

## 三、电气标准与硬件连接

UART为协议层规范，物理层存在多种电平标准适配不同场景。

### 3.1 常见电平标准

| 电平标准   | 逻辑电平定义                   | 典型应用场景                 |
| ---------- | ------------------------------ | ---------------------------- |
| TTL电平    | 逻辑1：3.3V/5V；逻辑0：0V      | 板级芯片直连、MCU默认输出    |
| RS-232电平 | 逻辑1：-3V-15V；逻辑0：+3V+15V | 工业长距通信、PC串口         |
| RS-485电平 | 差分信号传输                   | 远距离多点组网、工业现场总线 |

### 3.2 硬件连接规则

TTL电平UART采用交叉连接，且必须共地：

1. 设备A TX → 设备B RX
2. 设备A RX → 设备B TX
3. 设备A GND ↔ 设备B GND

共地是通信可靠的必要条件，缺失会导致参考电平不一致，引发采样错误与乱码。
